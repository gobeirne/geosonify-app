Privacy

Last updated 20 November 2026

Geosonify runs in your browser. There is no Geosonify server, no account and no advertising. Places, shapes and passphrases are worked out on your device. This page says exactly what leaves it.

The website itself

geosonify.org is a set of files served by GitHub Pages. When you open a page, GitHub receives the request, including the link's address. For an ordinary shared link that address contains the place, in encoded form; for an encrypted link (?enc=) it contains only the encrypted text. GitHub's handling of these requests is covered by GitHub's privacy statement.

Visit counting

To know whether anyone uses Geosonify, and whether people arrive from Wikipedia, each page load may be counted by GoatCounter. The count sends only the kind of page (the home page, a link from Wikipedia, a display link, an encrypted link or another shared link), the site you came from, and your screen size. It never sends the page's address, so it never sends a place. There are no cookies and nothing is stored on your device. GoatCounter, like any server, sees the IP address and browser of the request; how it treats them is set out in GoatCounter's privacy policy. If your browser asks sites not to track you (Do Not Track or Global Privacy Control), nothing is counted. Only the site's owner can see the counts.

Maps and imagery

To draw a map, your browser fetches tiles from the map service you choose (OpenStreetMap, Esri and others), and in the sky view, survey images from CDS in Strasbourg and its mirrors. These services therefore learn roughly which area is on your screen, as with any web map. That cannot be avoided while a map is shown.

Lookups that use the position

A few features ask an outside service about the position itself:

All of these are switched off whenever the position is meant to be private: while a grid passphrase or obfuscation is on, while hard encryption is on, and for the rest of the visit after an encrypted link has been opened. Only map tiles still load.

Searches you type yourself, such as a place name, a Wikidata ID or a file's address, are sent to the service that answers them (OpenStreetMap, Wikidata, Overpass, or the site holding the file).

Code libraries

Some program libraries load from public code hosts (unpkg, jsDelivr, OpenCV's documentation site and CDS), at pinned versions and, where possible, checked against a fingerprint so a changed file is refused. These hosts see that a page asked for the library, not what you are doing with it.

Your location

The "show my location" button and Track use your device's location only on your device: to draw the blue dot, or to move the place you are encoding. It is never sent anywhere by Geosonify and never becomes part of a link unless you share the place yourself.

Encrypted links and passphrases

Passphrases are never sent anywhere and never stored. An encrypted link is decrypted on your device; after it opens, the address bar keeps showing the encrypted link, so the place does not reach your browser's history or a copied address, and reloading asks for the passphrase again. Requests to other sites carry only geosonify.org as the referrer, never the page's address.

What is stored on your device

Your settings (which cards you show, their precision, map imagery, sound settings, whether you have seen the introduction) are kept in your browser's local storage on this device only. Clearing the site's data in your browser removes them.

So that links open without a connection, a service worker keeps a copy of the app's own files (the page, its scripts and the libraries it loads) in your browser's cache on this device. It never stores the address you opened, so it keeps no place, and it stores nothing from map, imagery or lookup services. Clearing the site's data removes it too.

Links you share

A link you send goes wherever you send it, and anyone who has an ordinary link can see the place. Use a passphrase or hard encryption when that matters.

A link can also carry the place after #? instead of ? (the Share card's "Keep the place out of server logs"). Browsers never send anything after # to a server, so geosonify.org's host and any network on the way never learn the place from such a link. Anyone you send it to still sees the place, as with an ordinary link.

Questions

Geosonify is open source: every request described here can be checked in its code. Questions or concerns: open an issue there.
