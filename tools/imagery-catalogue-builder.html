Imagery catalogue builder

A developer tool, not part of the app. It reads every layer in imagery-sources.txt, asks each server for its description and coverage, test-loads sample images in Web Mercator, and writes the catalogue the app's Aerial date list uses. Run it from geosonify.org (so the browser's cross-origin rules are the app's own), then download the catalogue and the report.
