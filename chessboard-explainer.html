How a place becomes a chessboard

The Chessboard card draws a code as a settled chess position. It is not a game: it is the code itself, and a Geosonify decoder turns the board back into exactly that code. This page runs the real encoder on a code and shows every decision it makes, square by square.

From base 16 to an integer

Hexadecimal is positional, like ordinary decimal, but each column is a power of 16 rather than 10. From the right the weights are 16⁰, 16¹, 16², and so on; A–F stand for 10–15.

    The decision treeroot → branch → leaf

    Picture every board the encoder can make as the leaves of a tree drawn upside down. The root holds all of them. Each fork is one choice (which pawns go on file h, say), and each branch leads to the subtree of every finished board that starts with that choice. A leaf is one finished board.

    The rank is the leaf's position in that agreed order, counted from zero. It is not an instruction like “put a pawn on h4”: the encoder finds the leaf by following, at each fork, the branch whose range of ranks contains it. The tree below is the real first two forks for your code; the grey rows bundle the other branches together.

    Warm-up: ten boards

    Say there are just ten finished boards, ranked 0 to 9, and the first fork splits them three ways:

    A2 boards0–1
    B ✓5 boards2–6
    C3 boards7–9

    Rank 4 lands in B, because 2 ≤ 4 ≤ 6. Skip A's two boards and the rank inside B is 4 − 2 = 2. That 2 is what the next fork uses.

    After files h and g the encoder carries on through files f to a, then the bishops, then the other pieces, each choice narrowing the subtree. The two kings come after the rank has found its leaf, and carry none of it.

      About this page

      The board in the walkthrough is the one the app draws. The page loads the same ChessboardLib the app does, records the counts it computes while encoding, and refuses to show anything unless the replayed board matches the codec's board square for square, decodes to the same rank, and passes the app's 64-square scan.

      Both Chessboard cards use the same board mathematics. They differ only in which code they portray, which is why a share link says ?fen= for one and ?hpfen= for the other.
